# FitApp Web

Diario de comidas, agua, sueño, peso y ejercicio. Funciona sin internet y los datos se quedan en el teléfono.

- Abrir en Safari del iPhone → Compartir → «Añadir a pantalla de inicio».
- Respaldo compatible con la app FitApp del iPad (Perfil → Copia de seguridad).
- Para publicar cambios: sube los archivos nuevos y cambia `VERSION` en `sw.js`.
